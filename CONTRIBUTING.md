# Contributing

This repository is a **workshop**, not a library. The most useful thing you can
do with it is take a copy and work through it.

## Using it

Click **Use this template** (or fork, or clone) to get your own copy. Then open
your coding agent in the directory and say "I'm ready" — `AGENTS.md` takes it
from there.

You are not expected to send changes back. Your copy is yours: rename things,
swap the database, throw away half the phases. Nothing here needs to stay
pristine.

## If you do want to send something back

Issues and pull requests are welcome but not actively solicited, and may sit for
a while. The most valuable kinds:

- **A trap that misfires** — something in `data/` that reads as a defect rather
  than a lesson, or a lesson nobody hits because it is too well hidden.
- **A figure that disagrees** with `data-guide.md`. Those numbers are recomputed
  from the CSVs; if your model disagrees, one of us is wrong and it is worth
  knowing which.
- **Agent portability** — the playbook is meant to work with any coding agent.
  If it assumes something your tool does not have, that is a bug.

Please do **not** send fixes to the data itself. The defects in `data/` are
deliberate — they are the exercise. `data-guide.md` explains each one and why it
stays.
